Install the Meetup import bookmarklet

It only reads the Meetup pages you're already viewing in your own logged-in browser, and stores nothing. Nothing is sent anywhere except back to this scheduler, via your clipboard.

Desktop: drag the button to your bookmarks bar

Playtest import

Drag it up onto your browser's bookmarks bar (show it first if it's hidden - usually Ctrl/Cmd+Shift+B). Then open a Meetup event's Attendees page and click the bookmark.

Phone: create a bookmark, then paste this code into it

  1. Copy the bookmarklet code below.
  2. Chrome on Android: bookmark any page (star icon or menu → Add to bookmarks), then open Bookmarks, edit that bookmark, and replace its URL with the copied code. Save.
  3. Safari on iOS: bookmark any page (Share → Add Bookmark), then open Bookmarks, tap Edit, tap the bookmark, and replace its URL with the copied code. Save.
  4. Open a Meetup event's Attendees page in that browser, then open your bookmarks and tap the one you just edited.

Using it

  1. Open the event's Attendees page on meetup.com.
  2. Click/tap the bookmarklet. A small overlay appears in the corner while it collects attendees and event comments.
  3. When it's done, the import JSON is on your clipboard (or shown in a text box to copy by hand). Paste it into the scheduler's Import from Meetup box on the Evening tab.

If Meetup's page layout has changed and the bookmarklet can't find something, it shows what went wrong rather than failing silently - fall back to pasting a plain list of names into the same import box.
